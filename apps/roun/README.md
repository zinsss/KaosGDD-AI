# 시간 탐험

어린이가 시간과 날짜의 경과를 직접 조작하며 배우는 독립형 PWA입니다.
백엔드, 로그인, 외부 API 없이 브라우저에서 동작하며 설정은
`localStorage`에 저장됩니다. 프로덕션 주소는 `roun.kaosgdd.net`입니다.

## 기능

- 시계 퀴즈: 제시된 시작·목표 시각 사이의 경과시간을 디지털·아날로그
  시계로 직접 찾아 정답 확인, 새 문제 생성, 풀이 애니메이션
- 달력: 시작일 선택, ±1일/±7일 이동, 월·연도 전환, 경과 구간 표시
- 날짜＋시간: 정수 분 단위로 날짜·정오·자정·월말·연말을 안전하게 이동
- 단위 배우기: 60초/60분/24시간/7일 경계의 묶음과 애니메이션
- 모든 증감 버튼의 500ms 길게 누르기, 키보드와 ARIA 레이블
- 설치 가능한 manifest, iOS 메타태그, 오프라인 service worker,
  방해하지 않는 새 버전 안내

## 개발 및 검증

Node.js 20 이상과 Corepack이 필요합니다.

```bash
corepack pnpm install
corepack pnpm dev
```

전체 검증:

```bash
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
```

프로덕션 빌드를 로컬에서 확인하려면 `corepack pnpm preview`를 실행합니다.

## 수동 확인 절차

1. 시계에서 오전 10:00을 시작으로 지정하고 +1시간을 여섯 번 눌러
   오후 4:00 및 경과 6시간을 확인합니다.
2. 오전 11:50과 오후 11:50에서 각각 +10분을 눌러 낮 12시와 다음 날
   밤 12시 전환을 확인합니다.
3. 달력에서 2026년 9월 4일을 선택하고 +1일을 여섯 번 눌러 9월 10일,
   경과 6일을 확인합니다.
4. 날짜＋시간에서 2026년 12월 31일 오후 11:50을 설정하고 +10분을 눌러
   2027년 1월 1일 오전 12:00을 확인합니다.
5. 각 단위 화면에서 + 버튼을 눌러 60초, 60분, 24시간, 7일의 묶음
   애니메이션과 상위 단위 1, 하위 단위 0을 확인합니다.
6. 개발자 도구를 iPhone SE(375px), iPad(768px), 데스크톱(1440px)으로
   전환해 가로 스크롤이 없고 모든 버튼이 48px 이상인지 확인합니다.
7. 프로덕션 빌드를 연 뒤 Application에서 manifest와 service worker를
   확인하고 Offline을 켠 후 새로고침해 앱이 계속 열리는지 확인합니다.

시간 계산의 자동 검증 사례는 `src/time.test.ts`에 있습니다.
